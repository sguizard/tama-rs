# tama-io

Format I/O for [`tama-rs`](https://crates.io/crates/tama-rs), a Rust rewrite of
[TAMA](https://github.com/GenomeRIK/tama) (Transcriptome Annotation by Modular
Algorithms).

Provides gzip-aware readers and writers plus FASTA and SAM handling (thin
[noodles](https://crates.io/crates/noodles) wrappers) used by the TAMA tools.

Most users want the [`tama-rs`](https://crates.io/crates/tama-rs) command-line
tool instead.
