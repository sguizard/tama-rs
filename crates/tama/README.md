# tama-rs

A Rust rewrite of [TAMA](https://github.com/GenomeRIK/tama) (Transcriptome
Annotation by Modular Algorithms) — a toolkit for building transcript
annotations from long-read (PacBio Iso-Seq / Oxford Nanopore) data.

All 34 original TAMA tools are implemented as subcommands of a single binary,
with **no Python, BioPython, or samtools runtime dependency**. Each tool is
validated byte-for-byte against the output of the original Python 2 script.

> **The package is `tama-rs`; the installed binary is `tama`.** The crate name
> `tama` on crates.io belongs to an unrelated project.

## Install

```sh
cargo install tama-rs
tama --help
```

## Use

```sh
# collapse mapped long reads into transcript models
tama collapse -s aligned.sam -f genome.fa -p out -x no_cap

# merge annotations across sources
tama merge -f filelist.txt -p merged

# convert a TAMA BED to GTF
tama format bed2gtf merged.bed merged.gtf
```

Shell completions are generated by the binary itself:

```sh
tama completions fish > ~/.config/fish/completions/tama.fish
```

`bash`, `zsh`, `powershell`, and `elvish` are also supported.
